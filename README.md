# Shuber Database Management System
A database management application developed for **Shuber**, allowing customer and driver information to be managed through a simple interface.

## Features
* View customer and driver records
* Add new customers and drivers
* Edit existing records
* Delete records
* User-friendly interface for managing records

## Technologies Used
* C#
* Visual Studio
* SQLite
* Windows Forms

## Database
As part of this project, I also designed and created the database used by the application. This included creating the relevant tables, relationships and data structure required to store customer and driver information.

Additional work demonstrating the database design and development process is included in this repository (Task Report).

## Additional Information
Task 4(a) - SHUBer is recognizing its drivers with awards based on the number of journeys they have completed. However, only journeys with a rating of 4.5 or higher will be considered. Generate a report that displays the top 5 drivers ranked by the number of journeys with a rating of 4.5 and above.

Task 4(B) - SHUBer is inviting its loyal customers to subscribe to the SHUBer One membership, which offers exclusive discounts and free rides in the future. Display the top 5 customers who qualify for SHUBer One based on the following criteria: 
-Must have taken frequent rides in the last three months. 
-Must spend an average of more than £100 per month. 
-Must have received at least five 5-star ratings across all rides.
